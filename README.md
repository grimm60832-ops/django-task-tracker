## Django Task Tracker

Task Tracker is a portfolio web application built with Django, inspired by enterprise task management systems like Jira. 
It allows users to manage projects, tasks, and team assignments efficiently.

## Features
- **Custom User Model** (`Developer`) extending `AbstractUser`.
- **Project Management** with categorization and filtering.
- **Task Assignment** via Many-to-Many relationships.
- **Search & Pagination** across all list views.
- **Automated Testing** and CI/CD compliance.

## Tech Stack
- **Backend:** Python, Django 6.1.3, SQLite / PostgreSQL
- **Frontend/UI:** Bootstrap 4, Django Crispy Forms
